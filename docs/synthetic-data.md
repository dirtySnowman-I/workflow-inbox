# Synthetic Data Plan

Workflow Inbox uses only fictional data.

No production records, customer information, private logs, credentials, scraped personal data, or data from previous projects will be used.

## Fictional Business

The demonstration represents a fictional company:

**Northstar Office Services**

The company handles office-maintenance requests.

## Request Data

Demo requests contain:

- requester
- summary
- status
- creation timestamp
- last-modification timestamp

Request IDs will be generated by the application.

The seed dataset may include records such as:
